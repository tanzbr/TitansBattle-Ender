## FreeForAll deathmatch
- `time.deathmatch_after_minutes`: minutes after battle start to trigger the deathmatch phase (0 to disable).
- `destination.deathmatch_entrances`: list of locations used to teleport remaining players when deathmatch begins.
- On trigger, remaining players move to the deathmatch arena and receive Speed II and Strength II until the match ends.
